Perfume Distribution — Sales Analytics Dashboard

## Overview
An end-to-end sales analytics project covering the full pipeline from raw data generation to an interactive Power BI dashboard. It includes revenue tracking against target, year-over-year variance analysis, RFM customer segmentation, and Pareto/ABC portfolio concentration analysis.

## Data Note
This project is based on real-world experience as an operations analyst at a perfume and cosmetics distribution company. The original company name, employees, customers, and financial figures have been fully anonymized — all data in this repository is synthetic, generated to mirror the structure, scale, and data quality challenges of the original production system (including realistic "dirty data" scenarios like inconsistent categorization, duplicate records, and missing values).

The goal of this project is to demonstrate the type of ETL, data cleaning, and business intelligence work performed in that role, translated into a US-market context (schema, currency, and terminology).
